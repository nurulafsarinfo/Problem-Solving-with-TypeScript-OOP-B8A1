## Assignment: Problem Solving with TypeScript & OOP

## Overview

This Assignment focuses on practicing core Typescript concepts and Object-Oriented Programming (OOP).

It includes eight problem solving tasks and two technically detailed blog posts on selected TypeScript topics.

## Technology Used

- TypeScript
- JavaScript
- Markdown
- Git and Github

## Problem Solving

All eight problem-solving tasks are implemented in  `solutions.ts`.

The tasks cover:

- Optional parameter and default values
- Union types and type narrowing
- Readonly tuples
- Generics and rest parameters
- Interfaces and array filtering
- Generic constraints using keyof
- Classes, inheritance, and access modifiers
- Promises and asynchronous operations
